# Информационная система «Гостиница»

## Описание проекта

Информационная система «Гостиница» — курсовой проект,
предназначенный для автоматизации работы гостиницы.

Система позволит управлять номерным фондом,
учитывать информацию о гостях, оформлять бронирования,
контролировать заезды и выезды, рассчитывать стоимость
проживания и применять скидочные программы.

## Основные функции

- Управление номерным фондом и категориями номеров.
- Учёт гостей.
- Создание и отмена бронирований.
- Проверка доступности номеров на выбранные даты.
- Регистрация заездов и выездов.
- Расчёт стоимости проживания.
- Применение скидок.
- Формирование отчётов о загрузке гостиницы и выручке.

## Технологический стек

- Python — основной язык программирования.
- FastAPI — разработка REST API.
- PostgreSQL — система управления базами данных.
- SQLAlchemy — взаимодействие с базой данных.
- Alembic — управление миграциями базы данных.
- Pydantic — валидация данных.
- pytest — автоматическое тестирование.
- Ruff — проверка и форматирование кода.
- DBeaver — работа с базой данных.
- Git и GitHub — контроль версий и совместная работа.
- GitHub Actions — автоматизация проверок проекта.
