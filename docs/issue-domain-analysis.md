# Анализ предметной области

Гостиница принимает заявки на проживание, распределяет гостей по номерам и регистрирует заезды и выезды. Администратор стойки размещения получает от гостя даты проживания и число проживающих. Для подбора номера ему нужны сведения о вместимости, тарифе и действующих бронях. Один и тот же номер может быть свободен сегодня и занят завтра, поэтому доступность определяют на весь запрошенный период.

При подтверждении заявки администратор закрепляет конкретный номер за гостем и сообщает стоимость. При отмене брони номер снова становится доступен на эти даты. По прибытии гостя администратор регистрирует заезд, а при отъезде закрывает проживание. Руководителю гостиницы сведения о бронированиях и фактическом проживании нужны для оценки загрузки. В более широкую предметную область входят скидки и отчётность по выручке.

Цель системы — дать администратору единый источник сведений о гостях, номерах и бронированиях, сократить ручную проверку дат и исключить подтверждение пересекающихся броней одного номера.

Для первой версии предлагается сценарий от подбора номера до подтверждения или отмены брони. Проверяемый результат — система отклоняет пересечение периодов для одного номера, разрешает следующий заезд в день выезда предыдущего гостя и освобождает даты после отмены.
